# Security Policy

## Supported Versions

We provide security updates and bug fixes for the following versions of **Amon Hen**:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Amon Hen, please follow these responsible disclosure steps:

1. **Do not create a public GitHub issue.**
2. Send an email with details and reproduction steps to:
   **[security@felixhrdyn.com](mailto:security@felixhrdyn.com)** (or contact via GitHub private vulnerability reporting).
3. Include as much information as possible:
   - Description of the issue
   - Step-by-step reproduction instructions or proof-of-concept
   - Potential impact
   - Suggested mitigations (if available)

We will acknowledge receipt within 48 hours and work with you to remediate the issue before any public announcement.
